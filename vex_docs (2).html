Quick Start

import vex

view = (
    vex.vex()
    .h2("Hello World")
    .text("This is a Components V2 message.")
    .button(
        vex.button()
        .label("Click me")
        .primary()
        .on_click(lambda i: i.response.send_message("Clicked!", ephemeral=True))
    )
)

await view.send_to(channel)

What is Vex V2

A fluent, minimal builder library for Discord Components V2 (Layout Views) in Python. Vex wraps discord.py V2 primitives with chainable APIs, pre-built paginators, confirmation flows, modals, cooldown utilities, and a lightweight command help registry.

Vex

Inherits discord.ui.LayoutView. The primary canvas for V2 messages.

CooldownCard

Pre-styled container for cooldown messages.

MethodDescription
build(retry_after, title="Slow down")Return a yellow ContainerBuilder.

Example

store = vex.cooldown_store(rate=2, per=5.0)

async def my_cmd(interaction):
    retry = store.check(interaction.message)
    if retry > 0:
        card = vex.cooldown_card(retry)
        await interaction.response.send_message(view=vex.vex().container(card), ephemeral=True)
        return
    await interaction.response.send_message("OK")

global_cd = vex.global_cooldown(rate=3, per=10.0)
retry = global_cd.check("cmd_name", message)
if global_cd.is_limited("cmd_name", message):
    pass
